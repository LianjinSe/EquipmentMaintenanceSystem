# 设备维保前端方向预览

这是一个与正式页面隔离的交互原型。页面位于 Tomcat 应用下的 `/prototypes/workspace/`；正式 `public/index.html`、`public/styles.css`、`public/app.js` 没有被原型引用或改写。

| 方案 | 探索方向 | 适合场景 | 代价 |
|---|---|---|---|
| 控制塔 | 深色、高密度侧栏和监控面板 | 值班室、管理人员同时关注多条异常 | 信息多，长时间普通办公可能显得紧张 |
| 工作日 | 浅色、宽松排版与任务叙事 | 每天处理工单、审批和计划的办公室工作 | 同屏容纳的数据较少 |
| 现场卡片 | 大尺寸任务卡、触屏操作和底部导航 | 平板、手机及现场快速处理 | 桌面端批量浏览效率较低 |

底部（现场卡片方案为顶部）的深色选择器可切换方案。快捷键 `1`、`2`、`3` 或左右方向键切换；`R` 重放当前方案。选中方案会写入 URL 的 `?v=` 参数，刷新后保持。

四个导航视图、工单详情与流转、设备详情、报修表单、维保任务完成、消息已读及筛选均可在预览中操作。**这些操作只修改页面内的虚构数据**，不调用 Java API，也不改变 Tomcat 中的业务记录；切换设计方向会重置原型数据，使比较时的数据一致。

确认选用方向后，再将对应布局和样式集成到正式页面，完整保留 Java 后端接口和现有业务能力，并移除这份临时预览。
