# 本地后端扩展说明

所有新增业务通过Java/Tomcat运行，原33个入口由明确模块处理，依赖外部服务的分支不会伪造结果。

|`AUTH`|本地密码登录、8小时令牌、账号停用、密码修改与会话撤销|SSO、验证码、注册、实名认证及登录设备/IP管理尚未接入；旧界面的 X-Demo-Actor 仍为演示兼容入口，不等于真实身份认证。|
|`ACCESS`|固定本地账号的功能权限和设备部门范围配置、版本与审计|菜单与字段配置仅保存元数据；没有供应商/企业租户隔离，旧演示路由未迁移到新权限模型。|
|`SETTINGS`|版本化字典、消息模板及安全类型的表单元数据保存|配置审批、动态前端表单和规则表达式执行未实现。|
|`ASSET`|调拨、停用、恢复、报废申请及审批；版本冲突、前后值、停用计划|财务折旧、Excel导入、借用和复杂审批链未实现；报废前必须结清未完成业务。|

## 账号与主数据

首次部署在数据文件旁生成 `.credentials.json`（含四个本地账号的随机密码）；API只保存PBKDF2密码哈希与令牌摘要。GET `/api/catalog`返回演示备件 `part-bearing`、仓库 `warehouse-main`、供应商 `supplier-demo`、合同 `contract-demo`、工具 `tool-meter`、课程 `course-demo`、SOP `sop-demo`。证书 `certificate-demo` 关联的设备ID须从catalog读取。

POST `/api/catalog/{kind}` 支持 warehouses(name)、parts(code/name/unit)、suppliers(name)、contracts(supplierId/active/validUntil)、standards(name/approved)、certificates(deviceId/standardVersion/validUntil/status)、knowledge(title/content/deviceModel/approved/sourceReferences)、tools(name/calibrationValidUntil)、courses(name/passingScore/validDays/questions)、models(deviceId/fileId/name/parts/instructions)、sopTemplates(name/steps)。这是管理员本地主数据维护，不执行脚本或调用外部服务。

GET `/api/records/{kind}` 查询功能集合；管理员可查全量，其他账号仅可查自身创建/所属记录，accounts/sessions不可导出。扩展数据在JSON的features对象下，文件在数据文件旁 `.files/` 内。升级兼容原schemaVersion=1的数据。

## 本地运行与复现

IDEA执行Maven `test`、`package`，部署 `target/equipment-maintenance-demo.war` 到本机Tomcat11。原一键入口可继续使用。开发验收须设置独立 `EQUIPMENT_DEMO_DATA`，不要对日常演示文件测试恢复。凭据、令牌、本地签名密钥、附件与备份均不提交Git。

新接口使用Bearer令牌，原演示页面仍兼容角色选择。此兼容入口意味着本系统尚未形成全站真实身份安全边界；部署仍只允许本机访问。扩展功能目前主要通过API调用，未给每项功能新增前端操作页。

## 文件与恢复

上传先申请 `/api/files/uploads`，随后向返回uploadUrl PUT原始字节（1–10MiB，长度/Content-Type须匹配，图片边长最多4096像素）。支持PNG/JPEG、UTF8文本、CSV、JSON及所有资源内嵌的glTF2.0；下载需认证并校验SHA256。标签QR由[ZXing](https://github.com/zxing/zxing/releases/tag/zxing-3.5.3)实际编码SVG。

备份请求 `{kind:"backup",scope:"database-and-files",restorePointId:null}` 生成真实ZIP和数据/附件摘要。恢复请求必须 `{kind:"restore",scope:"database-and-files",restorePointId:"...",confirm:true}`，校验清单/HMAC/附件后恢复并撤销所有会话。它是本机恢复能力，不是异地灾备；密钥须单独保管。

## 重要输入补充

库存kind支持issue/return/receipt，领料工单须在in_progress，退料不得超过净领料；数量最多3位小数。采购申请可通过action接口approve后receive，receive需warehouseId。SOP后续提交须提供返回version，steps须为模板步骤的连续前缀。离线operations额外需要action（createOrder/completeTask/completeOrder/readMessage），payload遵循对应原接口。location.position可提供accuracy，缺少设备位置或精度时matched=null。规则评估AI使用kind=threshold_evaluation，inputs含metrics/thresholds；它是确定性规则。
