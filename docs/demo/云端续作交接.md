- `src/domain.mjs`：业务规则和假数据。按上海日期计算到期；变更要求 version；本地存储的复制事务由服务器控制。
- `src/server.mjs`：服务与路由，默认绑定 127.0.0.1:4173。数据位于 data/demo.json（已忽略）；支持 PORT、DATA_FILE。
- `src/contracts.mjs`：API 注册表。所有预留路由只是设计草案，不能称为实现。
