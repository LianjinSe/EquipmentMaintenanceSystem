## 页面实测

在 `http://127.0.0.1:4173` 的本机浏览器打开了页面；首页、设备台账、维修工单、维保任务、计划及接口清单都能正常显示。默认浏览器视口下截图可读，未见主要版面遮挡。

| 场景 | 页面可见证据 |
|---|---|
| 维修工单 | 样例 `WO-0001` 从待派单 → 待接单 → 维修中 → 待验收 → 退回维修 → 再次完工 → 已关闭；详情保留两次完工和两次验收记录 |
| 演示角色 | 管理员派单、维修工接单及完工、管理员验收；切换角色后可见对应动作和消息数 |
| 点检异常 | 巡检员完成 `PM-0003`，其中“主轴声音”标异常；任务完成后可点击关联工单，打开 `WO-0002`，故障描述含异常说明 |
| 设备 | 管理员新增虚构的 `EQ-004`，列表显示编码、位置、分类；台账数量从 3 增至 4 |
| 计划 | 新增“演示泵每日点检”，手动生成 1 项到期任务，随后计划可暂停并显示“已暂停” |
| 消息 | 管理员消息弹窗显示未读记录，标记后该条变为“已读” |
| 预留接口 | 展开 `AUTH` 显示输入草案、前置依赖、验收条件；点击验证按钮后页面显示 `AUTH · NOT_IMPLEMENTED` |

页面交互验证使用浏览器自动化的键盘 `Enter`/`Space` 操作激活按钮与复选框，表单通过可访问名称填写。浏览器自动化工具的鼠标定位在部分内容按钮上没有稳定命中，因此**未把鼠标点击体验宣称为已完整验证**；键盘路径与业务 HTTP 测试均通过。
