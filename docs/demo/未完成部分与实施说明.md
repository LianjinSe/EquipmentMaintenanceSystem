# 未完成部分与实施说明

更新时间：2026-10-02。原33个预留入口已有本地后端处理器，局部范围逐项列在[本地后端扩展说明](本地后端扩展说明.md)，调用契约见[API.md](API.md)。77条路由可访问不等于原103张功能卡片完整交付。

## 身份与组织权限

已有本地密码登录、PBKDF2密码哈希、8小时令牌、账号停用、改密、会话撤销、功能授权、部分设备部门及记录所有者检查。原界面和27条原路由仍兼容可自行选择的 `X-Demo-Actor`，尚未形成全站真实身份边界。

继续开发时，应把原页面切换为账号登录，将所有原接口的actor绑定到会话，移除真实环境中的演示头，再扩展组织、供应商账号与企业归属。ACCESS里的menus/fields只保存元数据，没有全站菜单、字段、导出和行级过滤。验收须覆盖直接调API、跨部门/外协、撤权后的文件和会话访问。

## 数据与部署

数据保存在单实例JSON中，写入在副本上执行并持久化后发布。库存并发测试覆盖同一Store的线程竞争，不能宣称多Tomcat实例事务正确。不要让IDEA根路径与脚本命名路径同时写同一文件。

BACKUP生成真实数据与附件ZIP，核对SHA256与本机HMAC，再执行显式确认的恢复并撤销会话。尚缺数据库、多进程锁、异地备份、自动备份计划、容量策略、RPO/RTO验收和密钥迁移。迁移数据库时需设计唯一幂等键、余额与流水事务、附件一致性及迁移对账。

## 业务覆盖

资产审批包含调拨/停用/恢复/报废，报废前要求结清未完成业务，停用设备不再生成任务。BOM保存版本并阻止环路；尚缺财务折旧、批量Excel导入错误行报告和复杂资产生命周期。

库存支持领料/退料/收货、请求去重、单位与净退料限制，采购支持申请批准及收货入账；尚缺盘点、批次序列、成本计价、发票结算和供应商端。旧完工表单中的耗材文字不会自动扣库存，调用领退料接口才会产生余额变化。

WORKFLOW验证并保存流程定义，LOWCODE验证并保存表单/语言元数据；两者没有作为执行引擎替代现有工单状态机。排程仅预览日期计划和同日资源冲突；尚缺生产日历、运行量/产量触发、技能自动派单、抢单、SLA计时和后台定时任务。

MTTR/MTBF本地口径以完工尝试为单位；没有运行/生产输入时返回null和missingInputs。OEE需计划时长、运行时长、产量、良品及理想周期。它们不是批准的费用/绩效口径，维度聚合未执行。REPORT生成实际CSV，PDF、打印模板与大数据异步导出仍待接续。

## 外部平台与设备

INTEGRATION可原子导入本地设备批次，其余ERP/OA/MES/HR分支没有配置便返回503并保存阻塞任务。MOBILE的微信/支付宝/native、COLLAB视频、PUSH微信/短信/邮件，以及AI预测/孪生/语音不会报告外部成功。

接入前需要平台本地配置、接口资料和测试账号，处理授权、超时、回执、限流、重试与对账，并做实际沙箱调用验收。当前阻塞记录没有自动重试器。

IOT是本地HTTP遥测入口，有重复/乱序与阈值告警处理，没有网关签名、真实点位映射或可信采集。QR标签是可解码SVG，NFC/RFID/打印机和扫码导航页面未实现。AR3D查询用户上传的内嵌glTF资产，无AR硬件定位与前端渲染器。LOCATION仅计算提交坐标和精度，明确 `physicalLocationVerified=false`，不能当实地到位证明。

## 安全标准、识别与签署

SOP保存顺序步骤与附件要求并阻止未完成任务完工；模板没有业务/安全负责人批准，不替代现场作业标准。COMPLIANCE校验证书与本地标准关系/日期，不推断法规或提供机构资质保证。提前提醒记录仍需定时调度器。

OCR关联图片并创建人工确认待办，value/confidence初始为null；没有识别引擎。AI阈值评估是确定性规则，不是预测模型。培训考试和证书是本地记录，不是外部资质或HR/工资依据。

SIGN保存明确版本的快照与本地摘要，SECURITY为审计导出生成HMAC。它们不构成认证电子签章或独立第三方存证，也不能证明导出前本机管理员未改历史。接续需合法服务方、明确签署权限、密钥保管及篡改/恢复测试。

## 前端与验收

“工作日”页面继续提供设备、工单、维保和计划流程，接口进展页显示扩展范围。扩展业务主要通过API操作，尚未为每项功能建立前端操作页。下个迭代可按业务链接入设备审批、库存领料、文件附件等页面。

本机测试包含单元/契约测试及独立启用的真实Tomcat HTTP验收。HTTP测试会写数据并执行恢复，必须使用全新隔离的 `EQUIPMENT_DEMO_DATA` 文件。生产/现场验收仍需要真实数据来源、责任人、容量、权限、硬件及外部服务证据。
